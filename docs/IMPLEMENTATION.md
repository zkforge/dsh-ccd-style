# 当前实现

更新日期：2026-10-03。兼容基线为 DSH `0.2.0-rc.2`、macOS、浅色与深色两种配色。模块边界见 [架构](../ARCHITECTURE.md)，实际验证与限制见 [验证记录](VERIFICATION.md)，后续事项见 [待办](TECH_DEBT.md)。

## 范围与验收基准

首版调整窗口、侧栏、新建页和聊天页的视觉与布局，使用 DSH 身份。Workspace、Session、消息、官方 Composer、模型、权限、工具与发送流程都由宿主持有。保留官方 Composer 与业务服务，仅在 `conversation.input.model` 注册共用模型／effort 展示组件。

用户认可的展示图在 [README](../README.md)。开发用 CCD 参考图保留在本地 `docs/reference/`，不进入 Git 或安装包。字体走系统栈，默认尾巴以 Geist（SIL OFL 1.1）打头：`assets/fonts/` 只放本机安装用的字体文件与 `OFL.txt`，**不进安装包**，未安装时自动回落到平台字体栈。视觉修改按同尺寸截图和 DOM 几何验收，不把展示截图当作完整交互验证。

| 模块 | 状态 | 默认 |
| --- | --- | --- |
| shell | implemented | 开启 |
| sidebar | implemented | 开启 |
| new-session | implemented | 开启 |
| conversation | implemented | 开启 |
| tool-calls | planned | 关闭 |
| statistics | implemented（数据未接） | 关闭 |

总开关 `enabled` 默认关闭。开启时挂载作用域样式与兼容适配，关闭时释放取得的资源；设置传输和清理流程见架构。

## 新建页

入口：`src/client/features/new-session/`。

- 问候块位于会话体顶部 16px（`--ccd-hero-top`）、与 Composer 输入卡列**左对齐**；标题、统计卡片与输入卡共用同一条左边缘（参考截图就是这么摆的，宿主自己的 headline 居中已被覆盖）。标题用参考自己的排版档位：20px／26px、字重 400（`--ccd-font-size-headline`）。官方 Composer 固定到底部。
- 工作区与 Agent 预设芯片同输入面板左边缘对齐，26px 高、8px 圆角、细边框。
- 输入卡片最大宽度 770px。未选工作区时，仅输入面板显示虚线；选择工作区与编辑器禁用状态由宿主处理。
- 默认提示语与正常聊天统一，中英文可见文本与 aria-label 同步；工作区或阻断提示优先。提示语单行省略，实际编辑器正常换行与增长。
- 统计卡片（`statistics`，默认关闭）挂在问候块下方 20px 处、与标题左对齐（左缘取 `50% - Composer 卡宽 / 2`），宽 480px，三段结构与参考同构：header（`Overview` 胶囊，24px 高、`#e6e6e6`、13px medium）→ body（3×2 统计格，44px 高、`#dadada`、5px 圆角；26×7 贡献热力图，格距 3px、四档 `hsl(217 70% 72／64／56／48%)`；底部一行书比对文案，11/17、`pt-4`）；卡片顶到统计格顶约 41px（8px 内边距 + 24px header + 8px 间距），tiles／heat／文案同属 body、彼此 6px，与参考实测的松紧一致（参考卡片换算后约 303px 高，这里是 299px）。颜色取自 `theme/tokens.css` 的 `--ccd-stats-*`，深浅两套都在那里。问候块高度随字号与语言变化，所以卡片偏移由 `mount.ts` 实测问候块高度后写进 `--ccd-stats-gap`，不写死。DSH 的 hero 区只有 `conversation.hero.brand.mark／workspace／agent` 三个小座位，没有承载整块卡片的插槽，所以卡片自持容器：插进 `.ST7X_W_composerStack`（问候块的父容器）、与问候块共用绝对定位坐标系，`compat/host-dom.ts` 登记 `heroComposerStack` 锚点，`features/statistics/mount.ts` 用 MutationObserver 在 hero 阶段重建、离开阶段移除、释放时整体拆除。**当前只画到静态卡片**：数字是参考截图里的样例值，真实聚合未接，因此默认关闭；规格、数据方案与未决项见 [统计卡片调研](STATS_RESEARCH.md)。

## 聊天页与共用 Composer

入口：`src/client/features/conversation/`；共用输入区几何在 `src/client/theme/composer.css`。

- 正文列宽 770px；调整消息气泡、工具行、推理行与代码块观感，保留原生滚动、执行、授权与工具展开。
- 助手正文链接常驻蓝色实线下划线；文件链接和行内路径仍使用官方导航回调。行内代码采用红色等宽字、浅灰底、1px 细边框与 5px 圆角，长标识符在列宽内换行；粗体沿用 600 字重。样式不覆盖紧凑推理／工具 Markdown、用户引用或 Composer，代码块保留原生高亮与复制入口。
- 助手正文表格是单张圆角卡片：1px 外框、表头浅灰填充、表头下一条略深的分隔线、行间发丝线，没有竖线；单元格 4px／10px 内边距，表格文字与正文同为 14px／24px，行距 33px，首行与末行的边框由卡片自己收口。列对齐（`:---`／`:---:`／`---:`）仍由宿主 Markdown 决定。样式同样只作用于助手正文，紧凑推理／工具 Markdown 与用户消息保留原生表格。四列及以上时宿主会给包装层加 `md-table-wide` 并把它撑到滚动视口的整个内容宽度（表头左缘仍钉回正文列），而这里的 Composer 与正文列同宽，借用出来的那截会顶出输入框；因此插件把该包装层收回正文列（`width`／`padding-left`／`margin-left` 归零），表格与输入框左右缘对齐，宿主自己的 `md-table-wide` 悬停横向滚动保留给「列的下限都放不进」的表格（例如 8 列：宿主每格 `min-width: 100px`）。
- 助手正文代码块是单张白底圆角卡片：1px 外框（`--ccd-border`）与 6px 圆角（`--ccd-code-radius`，与表格卡片同一条参考曲线）。宿主用同一层冷灰分别给外壳、语言横幅和 `pre` 上色，横幅的外包裹层还会回落到页面 token，因此这四层都被重绘成纯白卡片（`--ccd-card`）＋透明内层，不再出现偏蓝的底色；语法高亮、语言标签、换行与复制按钮仍由宿主提供。样式同样只作用于助手正文。
- 输入面板最小高度 42px，控制行高 28px，间距 4px；附件轨与面板合成连续表面，缩略图和面板共用 10px 圆角。
- 发送／停止按钮固定在面板底部右侧，24px 按钮、16px 图标，底边间距 9px；同时显示两按钮时留 6px 间距。图标采用 DSH 共享库几何，归属写入 LICENSE。
- 原生速率、缓存命中与上下文读数放到模型选择之前。速率读数取宿主标签中带斜杠的一段；用量读数取宿主已经算好的缓存命中份额（没有可算的计费用量时回退到用量总量），宽列显示、容器 ≤700px 只留图标，上下文保留百分比；读数详情仍由宿主提供。
- 尾侧簇（两个读数、上下文环、模型与 effort）共用同一个 6px 间隙，最后一个按钮落在控制行的右内边缘：距输入面板右缘 11px（4px 行内边距 + 7px 按钮内边距）。宿主 trailing 组末尾的空 activity 座位（语音输入未启用时）不再占用组内 12px 间隙，模型与 effort 因此贴住右边缘；该座位被占用时仍按原生布局展开。
- 模型与 effort 为独立按钮：模型直接打开可搜索的目录列表，effort 打开约 220px 白色滑块浮层。浮层按首选 `zanwei/claude-model-selector` 还原轨道、滑钮、文字切换、磁性拖动、阻尼弹簧与最高档紫色像素场，支持键盘及减少动态效果；内容只有标题（`Effort` + 当前档位）、帮助提示、`Faster／Smarter` 轴与滑块，不再有 `Recommended` 行；可选档位／名称来自当前模型真实能力，模型推荐档仍决定未保存显式档位时的初始预览档。
- 两个按钮共用官方 ModelDirectory 与 select，保持 `/model` 同步；吸附完成才提交，失败恢复保存值。插件关闭后恢复原生合并菜单。实现位于 `src/client/features/model-controls/`，由 apply 为新建／聊天共用挂载。模型名与 effort 的选值墨色是 `--ccd-text-strong`（浅色纯黑、深色纯白），两者都是 400 字重：强调由墨色承担。工具行那条「行内按钮一律次级灰」的规则（特异度 0-2-2）会盖过控件自身的单类规则，而两个触发器与浮层都在这一行内，所以这条墨色写在它之上；provider 分组标题仍是次级灰，原生触发器（子会话座位）取同一墨色。
- 模型组按剩余空间限宽，effort 保留、模型名按需省略；≤560px 时权限控件只留图标。布局依据实际输入列，而非窗口宽度。
- 聊天顶栏合并成 49px 单行：会话标题 → 对话／轨迹 → 智能体团队与原生操作。被动模式展示隐藏，团队完整文字和操作入口保留。
- 顶栏尾侧固定为「打开方式 →（日程）→ 终端 → 浏览器 → 更多 → 右侧栏开关」：统一 28×28 命中盒、16px 图标、2px 间隙，簇右缘距列右缘 12px；≤520px 列宽降为 24×24 与 8px，≤420px 再省略会话标题（原生按钮与团队入口全部保留）。垂直方向沿用宿主的 10px 上内边距与 30px 行高，行中心与参考图一致。
- 「打开方式」显示为通用打开字形，点击任意位置都弹出原生应用菜单，不再直接打开上次的应用；宿主没有可选应用菜单时整块不渲染。终端／浏览器两个入口打开右侧栏对应页签，已有同类型页签时聚焦它，页签类型不存在时不注册。
- 视图轨道固定 `80×22px`，每格 `40×22px`。标题自然宽度上限 112px；标题与轨道、轨道与团队的可见间距均为 10px，不随右栏拖动切换断点。
- macOS 侧栏收起时省略会话标题，保留窗口控制区让位。视图选择切换使用 180ms 动画；框架轨道变化即时校正滑块，减少动态效果偏好下关闭动画。
- 空白会话页的顶栏只有角落座位一个控件（右侧栏收起时的「打开右侧边栏」）。宿主用 `.headerBlank .headerCorner` 的 `margin-left: auto` 把它留在尾侧，插件只在有标题与工具组的填满行里改用固定的簇间隙，空白行保留原生自动边距，因此这个入口仍在列右缘 12px 处，不会落到窗口控制区旁边。

- 顶栏下缘不再有分隔线：宿主那条 `.5px solid` 的发丝线被画成透明（边框宽度保留，顶栏高度不变），标题栏与正文连成一片，与参考图一致。
- 正文滚动视口的上下边缘各有 24px 渐隐，数值与宿主内部请求面板（`fadeTop`／`fadeBottom`）一致，且只有那一侧还有内容时才会出现：停在正文顶部时首行不会被压暗，滚到底时末行保持实心。上边缘贴滚动视口顶部（顶栏下缘）；下边缘贴在常驻 Composer 的**上沿**——滚动视口本身一直延伸到窗口底边，贴在它自己的底边会落在输入卡后面、什么也淡不掉。两个事实由 `compat/conversation-fade.ts` 从宿主滚动状态派生，渐变由 `features/conversation/conversation.css` 用页面主体的两个伪元素绘制；空白会话页共用同一个滚动视口，因此新建页一并生效。
- 这一层是**画上去的渐变，不是遮罩**：常驻 Composer 是滚动视口的子元素（吸附在视口底部的座位），给滚动视口加 `mask-image` 会把输入卡连同正文一起擦掉（实机验证中确实如此）。伪元素画在正文之上、Composer 的 `z-index: 7` 与「回到底部」按钮的 `z-index: 8` 之下，`pointer-events: none`，因此输入卡、悬浮按钮与所有交互都不受影响。
- 下方那一层覆盖 Composer 的**整个占位**，不只是 24px 渐隐带：输入卡上方的槽位（`conversation.input.dock` 里的计划／任务行等）会把 Composer 的顶边抬高，而那一带的输入卡表面是半透明的，正文会透出来变成"鬼影"。渐变层用画布色铺满 Composer 顶边以下的整片区域、只在上沿留 24px 渐变，于是这些行渲染在自己的干净背景上；实测同状态该区域墨量从 1,651,578 降到 26,347（**-98.4%**）。

兼容层负责菜单翻转、统计几何、视图滑块、账号展示、提示语适配、正文边缘渐隐状态与顶栏「打开方式」的模式标注。顶栏两个新增视图的注册入口在 `src/client/features/conversation/header-actions/`；选择器来源和版本依赖见 [兼容说明](DSH_COMPATIBILITY.md)。

## 配置与设置页

入口：`src/host/index.ts`（Config）、`src/shared/config.ts`（规范化）、`src/client/theme/`（token 计算）、`src/client/features/settings/`（页面）。

- 用户在侧栏「插件」→ `dsh-ccd-style` → 组件行 `ui-skin-ccd-style` 打开配置页；页面属于插件自己的行配置插槽，**关闭界面后仍然存在**，可以随时开回来。主题行也照常可用：它写的是宿主的偏好，不属于本插件的启用状态。
- 界面上的可配置项只保留当前有意义的：总开关 `enabled`、四个已实现模块的开关、「外观 → 主题」、`appearance.canvas`／`appearance.sidebar`、`fonts.uiLatin`（界面字体）与 `fonts.code`（代码字体）。行里不放说明文字，页脚在没有写入时保持空白，只在写入中／已保存／被拒绝时出现一行状态；唯一的例外是两个背景色行下方那行灰色说明（`.ccd-settings-note`）：「自定义背景色只作用于浅色模式；深色模式使用内置深色调色板。」它说的是这对字段的作用域，所以挂在两行之后，而不是每行重复一次。
- 只走 YAML 的进阶字段：`debug`（控制台排障日志）、`fonts.uiCjk`（西文与中文分开指定时才需要）、`features.tool-calls`（尚未实现）、`features.statistics`（卡片已实现、真实数据未接）。它们仍在 Host schema 里，配置页不展示。
- **即时生效，没有保存按钮**：开关、色块、字体选择一改就提交一次原子 `mutate`，写入当前 profile 的 `cordis.patch.yml`；文本字段（十六进制色值、字体族名）在失焦或回车时提交，避免半截输入到达设置边界。页脚只留一行状态（即时生效说明／写入中／已保存／被拒绝），失败时不改动界面值。
- 页面自己校验：颜色须为 `#rgb`／`#rrggbb`（提交前归一成小写六位），字体名只允许字母、数字、空格与 `._-`、长度 ≤64，非法值就地提示且不写盘；Host 的 schema `pattern` 是第二道闸，`adoptConfig` 对手改 YAML 兜底（永不抛错）。
- 「外观 → 主题」是宿主主题偏好的另一个入口（跟随系统／浅色／深色三格，16px 图标按钮住在 92×32 的槽里，选中格抬起成 1px 描边的卡片）。槽与选中格读 `--ccd-track`／`--ccd-card`／`--ccd-border-soft`，并带宿主 token 兜底，因此启用时与参考图一致（浅色槽 #f3f3f2、选中格纯白；深色槽 #1f1e1d、选中格 #30302e），插件关闭时这页仍按宿主调色板可读。它读 `getTheme().preference`、写 `setTheme()`、订阅 `theme/change`，本身不保存任何值，也不会与宿主自己的 Appearance 行不一致；箭头键在组内移动选择并循环。
- 深浅两色各有一套内置调色板（`theme/tokens.css` 的根标记块与宿主 `body[data-ds-dark-theme]` 块，`theme/palette.ts` 的 `BUILT_IN_DARK` 与之逐字节对应），token 层则把每个 `{ light, dark }` 成对交给 `ctx.theme.overrideTokens`：深色下画布 #262624、侧栏 #1f1e1d、卡片 #30302e、边框 #3e3e3b，正文与次级文字对画布的对比度分别为 13.2:1 与 7.1:1（浅色为 16.1:1 与 4.9:1）。轨道槽（`--ccd-track`）在两种配色里都**下沉**而不是抬起——浅色 #f3f3f2、深色 #1f1e1d——否则深色下抬起的那一格（顶栏视图切换的滑块、配置页选中的那格）会和槽同色而看不出来。effort 浮层、正文表格、代码卡片与边缘渐隐都只消费这些变量，因此两色一起跟随。
- 颜色只做「会话画布 + 侧栏」两项：配置后由 `theme/palette.ts` 派生卡片、轨道、悬停、选中与三档分隔线，并同步宿主语义 token；未配置时不下发 `--ccd-*`，内置调色板仍由 `theme/tokens.css` 唯一持有，外观与改动前逐字节一致。**配置色是浅色画布的选择**：深色侧固定用内置深色调色板，不把为浅色挑的颜色搬过去。
- 布尔项是 36×20 的滑动开关（宿主 `Switch` 的尺寸与 token，自绘：该组件所在包不在本项目的类型基线内，也不为此新增依赖）；整页是单列卡片，宽度上限 760px。
- 字体行点「选择」展开**行内**字体列表（首次展开时调 `window.queryLocalFonts()`，按族名去重、`zh` 排序后缓存一次）：搜索框 + 240px 滚动区 + 键盘 ↑↓/Enter/Esc，候选项用自身字体预览。不用原生 `<datalist>`——它的弹层是系统控件，样式不可控，在桌面窗口里滚轮也滚不动；环境不提供清单（无 API、未授权、返回空）时列表位置显示说明，输入框照常手填。
- 字体只接受单个字体族名：界面字体与中文（`uiCjk`，仅 YAML）按「界面 → 中文 → `--ccd-font-fallback`」组成栈，代码字体按「用户字体 → `--ccd-code-fallback`」组成栈，同时写宿主 token 与插件 `--ccd-font-*`；三项都留空时不覆盖任何字体变量。
- 控件形状对齐参考截图：布尔项是 36×20 胶囊开关（开启态用宿主的蓝色静态 token `--dsw-static-blue-450`）；字体是**整块**下拉框（值 + 内嵌 chevron，无内部分割线），点开菜单；背景色只有十六进制文本框，没有色块预览；按钮是带边框的安静按钮。分节不用卡片外壳，只用节标题 + 行间细分隔线区分。
- 字体菜单是插件自绘的定高卡片：无边框、`--dsw-radius-md` 圆角 + `--dsw-elevation-prominent` 阴影、与下拉框**行首对齐**；搜索框 + 260px 滚动列表，选项是纯文本行（34px、无分隔线），**当前项在行尾显示蓝色 ✓**；清单里没有的族名在搜索框输入后，第一行给出「使用“xxx”」并走同一套校验；菜单跟随锚点重定位（不因滚动而关闭），Esc／外部点击关闭。
- 边界：背景色只覆盖插件声明的两个表面，宿主浮层与模态仍走自己的调色板；右侧栏终端、文档预览与数学公式保留各自字体。深色下插件的两套调色板都可用，但自定义背景色只在浅色侧生效（按模式各配一套颜色尚未提供）；effort 浮层与模型弹层用的是插件自己的深色值，宿主原生菜单则是宿主自己的深色值。

## 尚未实现

`tool-calls` 保留原生展示，后续可从 `tool.call.toolview` 扩展；不能丢失执行、结果、失败、授权与子调用信息。`statistics` 的卡片视觉已按参考落地，但 DSH 没有官方的跨会话聚合接口，聚合需由插件自行折叠会话日志，**真实数据尚未接**，因此默认关闭；规格、可复用实现与挂载位置见 [统计卡片调研](STATS_RESEARCH.md)。其他待办集中在 TECH_DEBT。

## 开发与验证入口

`npm run check` 执行完整本地检查，`npm run pack:local --cache .cache/npm` 生成安装包，正式安装与升级步骤见 [安装指南](../install.md)。`lib/` 为生成目录，`scripts/lib/` 为构建共享源码。

| 工具 | 用途 |
| --- | --- |
| `scripts/desktop-probe.mjs` | CDP 表达式、截图、DOM 与控制台检查 |
| `scripts/desktop-responsive.mjs` | 多组尺寸量测与截图 |
| `scripts/desktop-preview.mjs` | 临时样式预览，clear 或刷新撤销 |
| `scripts/desktop-coldstart.mjs` | 按明确的重启范围执行冷启动与渲染层检查 |

工具使用说明在各脚本头部；浏览器工具依赖本机 Playwright 与 Chromium，不随安装包分发。新增功能后同步本文件、兼容说明与验证记录。
